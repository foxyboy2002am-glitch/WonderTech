# WONDERTECH | واندر تك

موقع WonderTech الرسمي، منشور عبر GitHub Pages.

## Structure
- `index.html` — page shell and metadata.
- `assets/site.css` — responsive styles, motion, and accessibility.
- `assets/app.js` — language content, routing, interactions, and site configuration.
- `assets/logo.png` — brand logo.

## Editing site details
Edit the `CFG` object near the top of `assets/app.js` to update the WhatsApp number, contact details, address, approved clients, and statistics. Keep contact links accurate and only add client names/logos you have permission to publish.

## Deployment
GitHub Pages should use branch `main` and folder `/(root)`. Keep the `CNAME` file in the repository root for the custom domain.
